1.1.1 Memory Structure

وهي تتكون لحظة فتح الـ Instance وهي عبارة عن جزء من الذاكرة يتم تخصيصه لعمل قاعدة البيانات Oracle وهي تتكون من جزئين:

  • 1- System Global Area (SGA)
  • 2- Program Global Area (PGA)
System Global Area (SGA)

وتسمى أيضاً Shared Global Area وهي جزء من الذاكرة يخصص للمعلومات التي تكون مشتركة ومتاحة لجميع مستخدمي قواعد البيانات، ومقاس هذه الذاكرة يتحدد بواسطة المتغير SGA_MAX_SIZE في ملف المتغيرات (Parameter File).

Mandatory Memory:

  • Shared Pool: يتم التحكم في مقاسه بواسطة SHARED_POOL_SIZE
  • Database Buffer Cache: يتم التحكم في مقاسه بواسطة DB_CACHE_SIZE
  • Redo Log Buffer: يتم تحديد مقاسه بواسطة LOG_BUFFER

Optional Memory:

  • Large Pool
  • Java Pool
  • Streams Pool
Program Global Area (PGA)

وتسمى أيضاً Process Global Area وهو جزء من الذاكرة يتكون خارج الـ Instance وهو يحتوي على معلومات خاصة للـ Server Process الحالي. وهي تحتوي على ثلاثة أجزاء:

  • Private SQL Area
  • Session Memory
  • SQL Work Area
أنواع العمليات (Processes)

هناك ثلاثة أنواع من الـ Processes:

  • User Process: يبدأ العمل عندما يطلب المستخدم الاتصال بقواعد البيانات
  • Server Process: يتم إنشاؤه لحظة الاتصال بالـ Instances
  • Background Processes: معالجات تعمل في قاعدة البيانات وتنقسم إلى Mandatory و Optional
